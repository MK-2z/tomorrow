# v22 功能修复包 - 紧急问题修复

## 已修复内容

### 1. 学生登入后可以输入学号
- 文件：`client/src/pages/quality-eval/QualityEvalPage.tsx`
- 修改：移除学生身份时学号字段的只读限制
- 效果：学生登录后评价表单的学号字段可手动编辑

### 2. 导出评价记录姓名和学号合并单元格
- 文件：`client/src/utils/export-excel.ts`
- 修改：班级和姓名列添加纵向合并单元格逻辑
- 效果：导出的Excel中，学号、班级、姓名都纵向合并贯穿整个学生的所有行

### 3. 上传的证明材料打开乱码问题
- 文件：`server/modules/upload/upload.controller.ts`、`server/main.ts`
- 修改：
  - 上传文件名使用纯时间戳+随机数，避免中文/特殊字符编码问题
  - 静态文件服务添加完整的 MIME 类型映射
  - 图片和PDF在浏览器中预览，其他文件下载
- 效果：上传的图片、文档等文件可以正常打开，不再乱码

### 4. 菜单栏只显示身份，不显示姓名和学号
- 文件：`client/src/components/Layout.tsx`
- 修改：移除姓名和学号的显示，只保留身份徽章
- 效果：菜单栏右上角只显示用户身份（学生/管理员/超级管理员）

### 5. 审查打回流程修复（部分）
- 文件：`server/modules/quality-eval/quality-eval.service.ts`
- 修改：标记单个指标为"待修改"时，不改变整体记录状态
- 效果：管理员标记待修改只是标记，整体状态不变；需要点击"打回"按钮才会将整体状态变为"待修改"

### 6. 导出功能优化（继承v21）
- 文件：`client/src/pages/review-list/ReviewListPage.tsx`
- 修改：
  - 导出按钮仅超级管理员可见
  - 导出必须先选中记录，未选中时按钮禁用
  - 移除"导出全部"按钮
  - 导出证明材料只导出选中的记录

## 待进一步修复的问题
